# Audio assets

The bundled WAV files are local game/UI cues used instead of Windows system sounds.
They are included with the repository so OpsecChess remains fully offline while running.

For future replacement, CC0 interface audio was researched from Colorosse's
Vellum Interface SFX pack (CC0 1.0), but the current bundled cues are generated
specifically for this project and do not require an online connection.
